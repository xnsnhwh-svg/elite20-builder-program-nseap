## 今天完成的四项

### 1. Agent 检索接口（DESIGN 7.4 / 9.1，V0.3 预留基础版）
- 新增端点 `GET /api/agent/context?q=&role=&type=&limit=`
  - 位置：`server/server.js`（路由约在 `/api/search` 之后）
- 复用现有 `searchEntries()` 加权搜索，新增辅助函数：
  - `statusTrust`：可信度排序权重 `stable>sample>review>draft>deprecated`
  - `roleAudienceAliases` + `entryMatchesRole()`：role 过滤，兼容 audience 中英混存（student/学生 等）
  - `toAgentContextItem()`：输出结构化上下文，含 `citation`（出处）+ `relationships`（显式关系）
  - `buildAgentContext()`：无 q 时按可信度+updatedAt 兜底排序；archived 默认排除；limit 上限 20
- 配套自动化测试：`tests/settings-api.test.js` 里 `"agent context API returns cited, trust-ranked, role-filtered knowledge"`（test 23）

### 2. Markdown 双向同步（DESIGN 9.5）
- 新增 `scripts/export-knowledge.js`：反向「库 → md 回写」
  - **只回写 frontmatter，保留正文**（人写的段落不覆盖）
  - audience 回写时用 `AUDIENCE_TO_ENUM` 反向映射回英文枚举（对齐 DESIGN 8.4）
  - summary 不回写（由正文派生，固化会造成冗余）
  - 只处理 `source` 指向 `knowledge-base/` 且文件存在的条目；upload/无源条目跳过；archived 默认跳过
  - 参数：`--dry-run` / `--id <id>` / `--include-archived` / `--verbose`
- 与既有 `import-knowledge.js` 合成双向同步，已验证**二次往返完全无损**
- `package.json` 新增脚本：`import:md`(= import-knowledge.js --update)、`export:md`(= export-knowledge.js)

### 3. 推 stable（DESIGN 8.7）
- 通过 API 审核流 `sample → review → approve → stable` 推了 **6 条核心条目**：
  `kb-challenge-001`、`kb-prompt-001`、`kb-project-001`、`kb-project-002`、`kb-course-001`、`kb-best-practice-003`
- 现状态分布：**stable 6 / sample 6 / draft 5**（总 17）。此前 stable 为 0
- 审计日志已记录完整流转（transition + approved）；stable 状态已 `export:md` 回写到 md 源

### 4. 状态枚举对齐（DESIGN 8.3）

  - `stable → [deprecated, archived, draft]`

- L1 校验从「仅 draft→review」改为「任何 → review 都校验」（补上 sample→review 的口子）
