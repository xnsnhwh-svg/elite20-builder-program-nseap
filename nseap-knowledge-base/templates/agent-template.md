# Agent 上下文条目标题

## 用途

这个 Agent 帮助谁、解决什么问题？

## 角色定位

它扮演什么角色？边界在哪里（能做什么、不做什么）？

## 上下文需求

它工作时需要哪些知识、数据或前置条件？应从知识库检索哪些类型的条目？

## 调用说明

在什么触发条件下调用它？输入是什么、期望输出是什么？

## 限制说明

有哪些已知限制、风险或不适用的场景？

## 关联知识

它依赖或产出哪些课程、挑战、提示词或项目案例？（对应 relationships）

## 评估 Evaluation

如何判断这个 Agent 的输出是否有效、可信？

## Agent Notes

补充给未来编排系统的说明：本条在什么问题、什么角色、什么任务场景下应被检索。
