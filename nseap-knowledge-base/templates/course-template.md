# 课程条目标题

## 用途

这门课程 / 这周内容帮助学习者掌握什么？

## 学习目标

学完后，学习者应该能做到哪些具体的事？（用可检验的动作描述）

## 周计划 / 内容安排

按时间或模块拆分的学习安排是什么？

## 前置要求

学习这门课之前，需要先掌握哪些知识或完成哪些条目？

## 教师引导

教师在带这门课时，重点讲什么、常见难点在哪、如何引导？

## 关联挑战与实践

这门课对应哪些挑战、提示词或项目案例，供学习者动手复用？

## 评估 Evaluation

如何判断学习者是否达成了学习目标？

## Agent Notes

如果以后接 Agent，它应该在用户问某个学习主题、周计划或学习路径时检索这门课程。
