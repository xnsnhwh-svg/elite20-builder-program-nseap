# 概览条目标题

## 用途

这份概览帮助读者快速理解什么？为什么应该先读它？

## 模块定位

这个系统 / 模块在整体产品或课程中处于什么位置，承担什么职责？

## 核心组成

它由哪些主要部分构成？各部分之间是什么关系？

## 使用介绍

新用户应该怎么开始使用？典型的第一步、第二步是什么？

## 适用对象与场景

学习者、教师、Builder 或 Agent 分别会在什么场景下用到它？

## 相关知识

读完这份概览后，建议接着看哪些课程、挑战或最佳实践条目？

## Agent Notes

如果以后接 Agent，它应该在用户问"这是什么 / 怎么开始"这类问题时检索这份概览。
